# Sans Bullshit Sans

Source for the Sans Bullshit Sans font. [Read about how this font was made](http://pixelambacht.nl/2015/sans-bullshit-sans/) 
or visit the [site](http://www.sansbullshitsans.com/) to see it in action.

This font is based on [Droid Sans](http://www.fontsquirrel.com/fonts/droid-sans) and released under the [Apache 2.0 license](http://www.apache.org/licenses/LICENSE-2.0).
